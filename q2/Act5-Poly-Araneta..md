1. What do all the methods (move(), special_move(), use()) in the previous activities have in common?

All these methods have the same purpose of performing an action. They can be used by different classes, but each class can have its own way of performing that action.

2. How does this activity show polymorphism in a gaming context?

This activity shows polymorphism because different characters and items can use the same method but perform different actions. For example, a Warrior, Mage, and Archer all have a special_move() method, but each one has a different special ability.

3. Can you think of other examples where the same action behaves differently depending on the character or item?

Yes. For example, an attack action can behave differently depending on the character. A Warrior can attack using a sword, a Mage can attack using magic, and an Archer can attack using a bow and arrow.
